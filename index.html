Okayama Leading Initiative for Value creation and Education

若者が「挑戦するなら岡山」と選ぶ未来を、ともに創る。

この岡山で学び、働き、力強く暮らしていける。誰もが未来への希望を抱き、Well-beingを実感できる岡山へ。

岡山大学が地域と積み重ねてきた学びの実践を、産学官金言と学生の手で県全体へ。OLIVEは「協議の場」ではなく、地域全体を俯瞰して未来を考え、翌日から動く「アクションタンク」です。

30秒でわかるOLIVE

足りなかったもの、やること、目指す先。この3つだけです。

Problem ― 足りなかったもの

話す場はあった。
動く場がなかった。

課題も処方箋も出揃っている。協議会・審議会・コンソーシアムで方針は決まる。だが実行は各機関に持ち帰られ、人も予算もつかない。議論が社会実装に届かず消える「死の谷」が、大学・自治体・企業のあいだにあった。

▶
Action ― OLIVEがやること

アクションタンクとして、
翌日から動く。

大学・高校・自治体・企業・若者を一枚の地図で見て、需給と機会をデータで見立てる。法人格と専任人員を持ち、PBL・連携開設科目・リスキリングを自ら設計・運営する。つなげる→見立てる→動かす→還す、の循環で。

▶
Outcome ― 目指す先

学ぶ・働く・暮らす魅力を、
在学中に体感できる岡山へ。

進学（18歳）・就職（22歳）・就職後（UIJターン）の三つの入口を同時に確保する。2040年に社会の中核を担う世代が「この岡山で学び、働き、力強く暮らしていける」と思える状態をつくる。

三つの魅力

学ぶ・働く・暮らす。三つの魅力を、一体で高める。

大学を残すだけでは、流出の時点が18歳から22歳にずれるだけ。地域の「学ぶ魅力」「働く魅力」「暮らす魅力」を高め、学生が在学中にそれを思う存分体感できるようにする。OLIVEの取組を、この三つの観点で束ねています。

学ぶ探究・PBLの授業（イメージ）
LEARN

学ぶ魅力

学ぶ魅力があれば、そこで学ぶ ― 幼稚園から大学院まで、答えのないテーマに問いを立てる学びへ

  • マナビの改革大学の教員と学生が幼稚園から高校までの学びの現場に入り、探究を「一緒につくる」
  • 起業家教育遊びから入り、手を動かし、「作りたい」を起点に挑戦する体験を重ねる
  • 大学間連携PBL企業・自治体の実課題を現地現物で。専門の異なる大学・学部が同じ現場で学び合う
働く地域企業と学生の交流（イメージ）
WORK

働く魅力

働く魅力があれば、そこで働く ― 在学中に地域の仕事を体感し、データで需給ギャップを埋める

  • 需給ギャップの可視化不足する業種・スキルをデータで確かめ、強みを持つ大学が育成を分担する
  • 在学中に地域の仕事と出会う採用目的ではない出会いと有償インターンで、地域で働くイメージを在学中に育てる
  • 岡山出身者の県外コミュニティ県外に出た若者とのつながりを保ち、戻る道と関係人口の接点をひらく
暮らす地域に滞在するPBL（イメージ）
LIVE

暮らす魅力

暮らす魅力があれば、還ってくる ― 在学中に地域で暮らす経験が、戻る理由になる

  • 地域に滞在するPBL暮らしを思う存分体感する経験が、通い続ける関係と戻る理由になる
  • UIJターン・還流・自走戻る道をひらき、補助金が終わっても回り続ける自走の仕組みを設計する
  • ユースボード若い世代が2040年の未来像を描き、「当事者」として直接提言する

OLIVEの4つの機能

つなげる → 見立てる → 動かす → 還す。

学ぶ・働く・暮らすの魅力は、学校・企業・自治体のどこか一つでは高められない。各組織だけでは持てない「弱さでつながり」、OLIVEが全体をオーケストレーションします。

①つなげる

HUB

既存のコミュニティ・コンソーシアムを有機的につなげ、情報も集める。各機関が「弱さ」を開示し合い、互いの強みで補う

②見立てる

THINK TANK

需給ギャップと、地域における大学の役割を見立てる。各大学の進路データを県全体で通して見る

③動かす

ACTION TANK

学ぶ・働く・暮らすの魅力を、PBL・連携開設科目・リスキリングで在学中に体感できる形にする

④還す

REINVEST

企業の教育投資が採用として戻り、次世代へ再投資。有料会員制度を財政基盤に

学びのフィールド

岡山をまるごと、学びのフィールドに。

県内の大学・高専が、企業・自治体・NPOと一緒に取り組む実践型の学び（PBL）を、27市町村の地図と分野・スキルから探せます。市町村を選んで、分野を選んで。答えのない実課題に揉まれる「知的修羅場」の体験と、地域に役立った「貢献実感」が得られる場へ、学生は気になるテーマを選んで飛び込みます。
